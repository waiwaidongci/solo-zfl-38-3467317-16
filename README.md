# 绳结成型与滑移验收

古船模型帆索的绳结成型登记、加载循环滑移记录与验收定案系统（零运行时依赖，Node 内置 http）。

## 运行

```bash
npm start                 # http://localhost:3038
PORT=4000 npm start       # 自定义端口
DB_PATH=/tmp/k.json npm start
```

数据以原子写（临时文件 + rename）保存在 `data/knot-acceptance.json`，重启后仍在。

## 验收规则（lib/knots.js）

每根索登记：索号、使用部位、**绳径 d、结型、绕圈数、尾长、预紧力、额定载荷**、成型员、验收员。

- 内置结型库给出**结型效率**（0.60~0.75）、最少绕圈数与最小尾长倍数：
  **最小尾长 = max(结型倍数 × d, 50mm)**；**最大允许滑移 = 1d**。
- 至少 **5 次加载循环**，逐次记录载荷与尾端累计滑移；循环序号服务端递增分配，
  重复、跳号、缺号一律 409 拒绝，累计滑移必须单调不减。
- 判定三档（任一拒绝项命中即拒绝，否则任一返工项命中即返工，全部合格才安全）：
  - **拒绝**：尾长缺口超过 1d / 循环不足 5 次 / 累计滑移超 1d / 滑移未稳定
    （末次增量 > 0.15d，或后三循环增量回弹超 0.3d）/ 载荷余量 < 1.25
    （结承载 = 额定载荷 × 结型效率，余量 = 结承载 / 最大试验载荷）/ 登记数据无效
    （含成型员与验收员同人）。拒绝时逐条列明原因。
  - **返工**：尾长缺口 ≤ 1d、绕圈数不足、余量在 1.25~1.5 之间。
  - **安全**：全部指标合格（余量 ≥ 1.5）。
- 页面与结果中给出**最小尾长**与**最大允许滑移**。

## 职责分离与不可覆盖

- 成型员只负责登记；验收必须由登记时指定的另一名验收员**签名确认**（签名不符 403）。
- 一次确认只生成一个不可变结果：重复确认返回 409 与原结果；确认后绳索冻结，不能再录循环。
- 并发确认 / 并发登记同一索号 / 并发录入同序号：按绳索串行化，**只成功一次**。
- 批量确认：先校验整批（不存在、已定案、签名不符），任一不满足则**整批回滚不留半批**；
  写盘失败同样回滚内存与磁盘。

页面显示统计、循环进度条、滑移趋势图（含允许上限红线）、危险项面板与定案封条。

## 测试

```bash
npm test                  # 26 个 node:test：领域判定 + API/并发/回滚/持久化
npm run test:browser      # Playwright 真实浏览器走查（7 项）
```

浏览器走查覆盖：安全 / 返工 / 拒绝（危险项列明原因）/ 8 并发确认只成功一次 /
批量回滚不留半批 / 服务重启后刷新仍在且不可重复确认 / 全程无页面 JS 错误，
截图输出到 `tests/screenshots/`。

无 root 环境安装浏览器系统库（Debian 12 arm64 示例）：
`npx playwright install chromium` 后按 `~/chromedeps/fetch-deps.mjs`
（仓库外的引导脚本）思路下载 arm64 deb 解包到 `$HOME/chromedeps/root`，
走查会自动把其 `usr/lib`、`lib` 加入 `LD_LIBRARY_PATH`；中文渲染需安装
`fonts-wqy-zenhei` 到 `~/.fonts` 并 `fc-cache -f`。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/knots` | 结型库与限值 |
| GET | `/api/ropes` | 绳索列表（含实时判定预览） |
| POST | `/api/ropes` | 成型登记（重复索号 409） |
| POST | `/api/ropes/:id/cycles` | 追加循环（body 须带 `expectedSeq`） |
| POST | `/api/ropes/:id/confirm` | 验收员签名定案（不可覆盖） |
| POST | `/api/ropes/batch-confirm` | 批量定案（失败整批回滚） |
